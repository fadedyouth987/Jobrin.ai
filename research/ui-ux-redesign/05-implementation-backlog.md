# Jobrin.ai Implementation Backlog

## Sequencing rules

Each item is an independently reviewable pull request. Security/correctness and broken journeys precede visual changes. Every data PR includes two-workspace isolation tests and preserves the server as the authority for workspace membership. Database changes receive forward and rollback migrations; presentation-only PRs revert cleanly by commit.

## Release evidence required after the backlog

The redesign is complete only after a staging workspace demonstrates account verification → workspace setup → customer → lead → scheduled job → field completion → quote → customer acceptance → invoice → test payment → correct business settlement → attribution, plus owner/manager/staff/viewer restrictions, two-workspace isolation, expired sessions, provider failures, keyboard use, 200% text, 320 px mobile, dark/light mode and long real-world content without overlap or clipped actions.

Presentation PRs may ship after their dependent correctness PRs pass. Client Portal, Templates, GPS, accounting sync and offline expansion remain unavailable until their explicitly marked backend work is reviewed and implemented.
